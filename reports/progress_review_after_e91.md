# Progress and strategy review after E91

This is a planning review, not a new experiment or permission to execute one.
E91 remains the latest completed experiment. Historical results and stopping
rules are unchanged.

## What we can conclude

Engineering progress is ahead of scientific progress. We have preserved failed
gates, reproducible computations and source uncertainty, but have not validated
a natural FL decipherment, opaque word meanings or independent semantic accuracy.
The natural semantic benchmark still has **0/4 qualifying new source works**.
Experiment numbers and passing software tests are not independent scientific
advances.

The strongest recent positive result is [E79](000079_interpretation.md):
**0.072877 bits/target** mean prediction gain across **13/13 exposed groups**,
using 98 units and 1,918 targets. Only 311 target probabilities changed. This is
an adaptive development result, not independent confirmation or translation.
[E88](000088_interpretation.md) found that exact three- and four-token overlaps
cover 6.41% and 2.76% of positive gain respectively. This narrows one explanation;
it does not exclude approximate templates, masking errors or annotation effects.

[E90](000090_interpretation.md) and [E91](000091_interpretation.md) provide a useful
new resource: 86 candidate Yid documents, an index, a source catalog and a combined
edition. All 86 individual documents occur byte for byte in the combined edition;
these are duplicate representations. The index has 86 distinct native-shaped URL
literals, not 86 authenticated posts or independent source groups. The package's
English renderings remain hypotheses. A Yid study would be a different resource
direction, not confirmation of the Kamri result on the same language.

## What should change

The work has become too fragmented around acquisition, accounting and parser
checks. Those checks protect evidence, but repeatedly turning routine integration
issues into separate milestones does not resolve the scientific bottleneck.

E91 is a concrete process lesson. Freezing a standalone-number/colon-label parser
before inspecting a declared development sample left all 86 candidate documents
without recognized unit blocks. Its provenance and duplication census is useful;
its zero-block result is an integration limitation, not a scientific negative.
Preserve that result, but do not repeat this workflow. Scientific outcome rules
and evaluation membership should be frozen; an unfamiliar format adapter should
first be developed on explicitly disclosed examples.

Prioritize usable, source-bound observations over more model features or repeated
reviews of already exposed packets. Keep stopped transport, archive-replay and
pagination routes stopped. A different acquisition route needs new evidence of
feasibility, not another retry of the same barrier. Automated review cannot supply
the independent semantic review still missing from this project.

## Recommended next bounded milestone

Register one adapter-development and corpus-accounting task using the saved Yid
package. Specify a small deterministic development sample covering candidate,
index and source-catalog formats; disclose every inspected example. Implement a
new versioned adapter, test it, then freeze it before one complete census of all
86 candidate files. Do not alter E91 or select examples using translation quality
or prediction outcomes.

The deliverable should be a complete ledger connecting document identity, literal
index locator, source claims and exact unit spans, with explicit unsupported
layouts, missing/conflicting joins and duplicate representations. Do not silently
repair failures after the census. Routine development checks belong inside this
milestone rather than becoming a succession of numbered experiments.

Then make an explicit feasibility decision before modeling: can a bounded,
documented corroboration route verify native text and supply usable independent
groups? If yes, separately register a small falsification test with fixed hard
alternatives and reserved evaluation groups. If not, stop the confirmation route
and state the missing resource. Annotation-only exploratory structure can remain
a declared development study; it cannot substitute for native corroboration or
semantic validation. Preserve the existing four-work semantic admission gate.

Measure progress by newly usable observations, resolved provenance, independently
testable claims and uncertainty reduced. Another model run or audit is worthwhile
only when it can change a stated conclusion. No document inspection, adapter
execution, acquisition or scoring was performed for this review.
