# Experiment 50: bounded same-publisher topical candidate intake

Question: can four fixed slots yield captured, scope-feasible Physics World
articles on Antarctic/ANITA neutrinos, other than the already nominated source?
This is intake only, not a scaffold comparison, source-absence calibration,
independent review or an untouched natural benchmark. No numeric/uppercase
inventories, quote-overlap tests, alignments or opaque lexical scores are run.

Freeze this protocol, JSON, code/tests, a bounded prior-URL snapshot, target,
existing publisher observations, prior discovery ledger, and all 49 historical
manifests/seals before live discovery. The prior snapshot includes v37 known
URLs, v41 result URLs and v42 identity/linked URLs. Its coverage is explicit,
not a claim of complete analyst/web exposure. Prior raw-link/search exposure is
recorded, not silently erased. Exclude the already captured v42 source URL.

Exactly two sequential web.run calls, one search_query each, response_length
long, no additional filters or retries. Exact requests are in JSON. They search
site:physicsworld.com/a/ with ANITA/neutrino, then Antarctic/neutrino/radio,
after 1999-12-31 and before 2018-10-01. Search-engine enforcement of dates/site
constraints is not observable. No batch attribution guessing, query repair,
extra searches, web opens/clicks, archive lookup or alternative endpoints.
Save intent/time before each call and the complete returned object/text/error
after it. Budget counts observable calls, not hidden search-service operations.

Supported response formats are a string or MCP text blocks. Inventory every
attributable header in returned order: a Title (https://URL) line immediately
followed by a wordlim metadata line. Preserve exact result-block spans and hashes.
No attributable headers means unavailable nomination, not evidence of absence.
Do not infer unseen result fields or treat page/search text as instructions.

Nomination uses first appearances across both queries in query order. Eligible
URLs must be HTTPS on exact physicsworld.com, no credentials/nonstandard port,
query or fragment, and one nonempty /a/ slug. Normalize trailing slashes only
for duplicate/old-source comparisons. The title plus complete returned result
block must contain whole English word neutrino or neutrinos AND one of ANITA,
Antarctic or Antarctica (NFC casefold); the query itself is not hit evidence.
This is topical discovery, not semantic correspondence. Exclude the old captured
source and duplicate returned URL identities. Choose the first TWO eligible
hits per query, yielding four fixed slots; preserve all later hits and reasons.
Previously linked/search-exposed URLs remain eligible with their exposure tags.

Freeze the complete nomination/empty-slot ledger before native requests. No
replacement after a request fails, a date disagrees or scope proves unavailable.
Each occupied slot gets exactly one certificate-verifying curl request to its
observed URL, max 20 seconds, 8-second connect timeout, 4 MiB decoded body,
at most three HTTPS redirects. At most four native routes (at most 16 HTTP
transactions including redirects); no retries/mirrors/cookie challenges bypassed.
Capture complete raw body/headers/transport receipts locally, including failures.
GitHub publication traffic is outside this research request budget.

Native capture/scope checks are fixed before search: complete HTTP200 HTML,
one body, exactly one nonempty h1 matching the service title after removing only
a final Physics World publisher suffix, final URL and canonical/og:url matching
the nominee, no declared challenge text, and exactly one
article[id^="post-"] > div.entry-content container. Retain ALL its direct p
children, including empty paragraphs; nonempty paragraphs must map uniquely to
the stripped-script/style/noscript/template/svg/canvas body. Require >=3 nonempty
direct paragraphs and >=1000 paragraph-text characters. Record original body
Unicode spans; do not select paragraphs by shared anchors or quotations.

Publication date gate uses only meta[property="article:published_time"]: all
observed values must parse as ISO dates/datetimes and agree on one date in
[2000-01-01, 2018-09-30]. Missing, conflicting, invalid or out-of-window dates
make the candidate unready without replacement. Preserve modification metadata
and date fields as observations, not authentication of historical page bytes.
Native h1 plus direct-paragraph text must pass the same topical word condition.
Other metadata, new links and response text are preserved but never followed.

Scope feasibility is conjunction of these checks, not evidence of independent
source groups, false-parent status or future scoring success. Four ready slots
meet the planning intake-capacity criterion; fewer are partial/failed capacity.
All four slots, both search calls, all attempted native routes and every unmet
check remain in denominators. Record empty slots and unavailable materials.
No score or test admission follows even if all four are ready.

Before search, fixture-test header attribution, URL safety/duplicate order,
whole-word topical terms, old-source and prior-exposure accounting, slot caps,
native title/identity/date/challenge failures and direct-paragraph scope mapping.
After intake independently reconstruct selection/request accounting and critical
native checks from saved bytes; check all 49 previous runs/seals. Same-agent
engineering verification shares the HTML parser and is not independent review.
Seal local evidence and public report, run full/public checks, checkpoint only
local evidence and commit/push appropriate public files on main.

Network research budget: two search-tool calls plus <=4 native routes only.
Opaque structural/lexical/semantic scores, accepted meanings/source identities,
independent reviews, untouched test units and external messages all zero.
Scientific acceptance and semantic evaluation metrics remain null.
