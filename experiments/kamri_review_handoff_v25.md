# Step 25: independent-review handoff and return validation

Registered before generating review bundles or validating a reviewer return. This step prepares the next review boundary from v23/v24 materials. It is not a semantic experiment or a completed independent review. No network, PDF extraction/rendering, source search, model, lexical retest, target scoring or external message runs. Both fixed nominees remain in order: western_esoterism, risk_math. All previous gates, failures, ambiguity and exposure remain unchanged.

Produce exactly two self-contained bundles, one per nominee, with an explicit member allowlist: full archived FL body, unchanged publisher PDF, fixed-window page images, existing publisher window prose, neutral instructions, material manifest and blank return template. Western uses v24 page extracts/images 90–94; Risk uses byte-bound v23 source prose/images 1–3. Copies preserve bytes. Whole PDFs are provided for provenance; correspondence claims are restricted to the fixed window. Whole-post coverage is unestablished. No prior reading-edition English, dictionary, model output, gap preference or accepted correspondence enters either bundle. Candidate source pairing and public source titles/URLs are disclosed, so these bundles are not blinded source-retrieval trials. A reviewer can be independent of prior predictions, but self-declaration cannot prove independence. All groups were previously exposed and remain ineligible for untouched validation.

Each return binds the packet manifest SHA-256 and exact FL/publisher text SHA-256. Offsets are half-open Python Unicode code-point offsets in the bundled UTF-8 text, including whitespace and the final newline; quoted text must match those slices exactly. Source page images/PDF govern layout, while text offsets govern reproducible references. Copied names, counts, order and plausibility are insufficient for word meanings. A reviewer must distinguish literal shared-language quotations from inferred relationships and unknown-language passages; no translation should be invented for the latter.

Require a named reviewer with role human or automated, an explicit independence declaration and description of prior exposure, a completed-return flag, language-scope observations with exact FL spans, an overall supported/rejected/uncertain source-relationship assessment, a full/partial/none/uncertain coverage assessment, boundary-check status, and limitations/uncertainty. Correspondence and counterexample lists may be empty; do not force positive matches or disallow an entirely uncertain finding. Relationship claims of support or rejection require at least one explicitly scoped cited evidence pair. Each pair has exact FL/source spans and a basis (literal shared-language text, citation, name-only, structural-only, or other documented evidence). Unsupported meanings cannot be admitted. Evidence pairs themselves remain reviewer claims pending adjudication. Reviewer completion, positive source relationship, and semantic admission are separate states.

The validator checks structure, binding, independence declaration and offsets. Valid returns are eligible only for recorded adjudication; semantic labels, source-identity admissions and untouched admissions always remain zero. It reports all detected problems, including stale packet/text hashes, absent/false independence declarations, incomplete forms, invalid scopes, out-of-bounds/incorrect quotes and unrecognized fields. Explicit semantic-admission attempts fail closed. It never edits original packets or silently replaces a return. Independently reimplement these checks before accepting a real return.

No actual return is manufactured. Blank templates must be rejected as incomplete in fixture tests; positive/negative/uncertain synthetic fixtures are test data, never reviewer evidence. If no independent reviewer return exists, finish the engineering handoff with review state awaiting_independent_return, zero independent reviews/labels/admissions, and null evaluation metrics. Do not count another pass by this assistant as independent review. The pending reviewer-route question does not authorize external contact or a sub-agent; those actions require an explicit human answer.

Freeze source/registration/code hashes before building; refuse existing bundle/run outputs. Build deterministic ZIP archives from exact allowlisted members, with no symlinks or external paths. Independently verify exact member sets/bytes, all offsets and blank templates, no prediction exports, all prior manifests/seals and immutable run accounting. Preserve the successful engineering verification receipt. New review returns belong in a new dated intake record and cannot modify this sealed zero-return handoff.
