# Experiment 49: citation-masking sensitivity of the two-paper comparison

Question: does the fixed publisher numeric score of six still exceed both paper
window maxima after a document-wide citation mask? This exposed sensitivity test
does not replace v47, identify an immediate source, establish meanings, or create
independent natural test units. V48 showed that most selected paper matches were
in citations/references; it did not license removing only those selected rows.

Before filtering anchors or scoring, freeze config, code/tests, original target
and scope, both full v47 inventories/assessments, page exports/PDF bytes, v48
selection/ledger, and all 48 prior manifests/seals. Reference boundaries were
chosen by structural text/image inspection, not by new scores: Neutrino Radar
page 7 offset 1013 begins the References heading; ANITA anomalous page 13 offset
1382 begins reference [1] after acknowledgments. Exact page-local offset/needle
and boundary-image hashes are frozen in JSON. Mask from each boundary through
the document end, including all subsequent reference pages and page footers.
These tails have no later non-reference section in the captured exports.

In every original saved page text, apply exactly this syntactic bracket pattern:
`\[\s*[0-9]+(?:\s*[,;\-–−]\s*[0-9]+)*\s*\]`. It includes numeric singletons,
lists and ranges, with spaces/newlines, comma/semicolon, ASCII hyphen, en dash
or minus sign. Do not expand ranges, infer reference identity, normalize digits
or repair unsupported brackets. Record every matched bracket and its original
page/global span. Matches ending at/before the reference boundary become inline
numeric-bracket masks; later matches are recorded as covered by the reference
tail. Scan page by page, without repairing citations split across page edges.
This rule may mask numeric intervals and miss other citation forms: describe it
as a syntactic sensitivity mask, not certified complete citation segmentation.

Merge those mask spans, retaining a complete reason ledger. Reconstruct each
full v47 inventory unchanged before filtering. Remove every original mixed
numeric/uppercase anchor overlapping any mask. Never edit/re-extract masked text,
filter by matching target keys, rescue a partial identifier, or choose a score-
dependent scope. Retain original anchor index, original page/global spans and
page-local coordinates; assign a dense new anchor index only for bookkeeping.
Keep every original page unit, including zero-retained-anchor reference pages.

Preserve every original v47 control draw, its family/draw ID and page order.
For each of the original 34 mixed-anchor permutations, filter removed original

not zero. Controls receive the same exhaustive search opportunity as observations.
Removing anchors can compress a window's textual span and increase a best-window
score; no favorable monotonicity assumption is allowed.

fixed original coordinates, no retained anchor overlaps a mask, dense/original

sparse/unavailable null. Report every family maximum and tie/greater count.
