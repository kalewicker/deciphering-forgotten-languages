## Training, learning and staging

Train on keys 11,29,47,83 only. The latent source vocabulary is `symbol0`–`symbol31`; training uses only classes0–23. For each key generate two independent-order aligned passages. Each contains three permutation cycles of all24 trained classes: sort class IDs by SHA-256(`v32|train|{key}|{passage}|{cycle}|{class}`), class ID breaking ties. After every seventeenth underlying symbol, insert the literal blocked token `copiedanchor{(i//17)%3}`. Thus each training passage has 72 source symbols plus four barriers. Query training aliases are `aliascode` plus the first20 SHA-256 hex digits of `v32|alias|{key}|{class}|0`. Source and query positions are supplied as aligned synthetic training supervision. The generator/key is not consulted by the learner.

The learner records every unblocked aligned query-form/source-form observation with training unit IDs and offsets. Admit a query form only if it has exactly one source outcome and appears in both distinct training units (minimum support2). Conflicts and insufficient-support forms stay unadmitted. Global mapping permits different key-specific aliases to share one source form. Barriers are never learned. Preserve the full observation ledger and all rejected forms; do not induce unobserved aliases.

Seal registration/input/code first. Prepare training only, learn and hash-freeze the mapping second, and only then generate the full test corpus. Test generation and scoring never revise the learned entries. Freeze public tests, separate oracle, mapping-based availability and benchmark before prediction. Save oracle-free predictions before loading test-origin labels for assessment. Generator code and keys are public: these are controlled development fixtures, not secret-key blind trials.

## Fixed test corpus and known origin traces

Use six new test passages, each length64. At source position i use class SHA-256(`v32|test|{passage}|{i}`) modulo24. Test order domains differ from training. Positions with (i+1) divisible by17 are overwritten by literal blocked anchors as above. Cross four seen keys with three vocabulary groups: seen (unmodified classes), sparse_unknown (replace classes at positions with (i+1) divisible by11 by `24 + i%8`), dense_unknown (replace positions with i divisible by3 by `24 + i%8`). Barriers take priority. Add unseen_key groups for keys101,131 with the ordinary seen-class streams. Total84 parents: 24 seen,24 sparse,24 dense and12 unseen-key.

Cross every parent with five mechanisms, total420 queries: bijective alias0; insert a distinct unblocked `inserted{base_id}at{i}` token after every seventh source position; omit every seventh source position; contextual aliases alternating occurrence parity0/1 for each unblocked source class; and swaps (6,7),(13,14),… of source-origin indices before alias0. Alias1 has never appeared in training. Preserve every query-to-parent origin, insertion null, deletion and alias parity in the separate oracle. Sparse/dense withheld source types and unseen-key aliases have no training entries. Reordering is not repaired in the references.

For each parent make three distractors: frequency-preserving shuffle of unblocked indices sorted by SHA-256(`v32|shuffle|{base_id}|{i}`); a different-pattern stream with source class SHA-256(`v32|negative|{base_id}|{i}`) modulo32 at unblocked positions; and an anchor frame with unique unblocked filler forms. All retain the parent's length and barrier positions. Also create a repetition-equivalent impostor by cyclically shifting source classes within0–23 and within24–31 separately, leaving barriers fixed. It preserves equality patterns while changing the frozen lexical constraints. Finally create a byte-identical duplicate of the parent in a different view/slot, preserving a remaining genuine observational ambiguity.

Five panels per query, total2,100: present (slot0 parent, slots1–3 shuffle/different/frame); absent (slots1–3); impostor_only (slot0 impostor plus slots1–3); parent_plus_impostor (present plus slot4 impostor); duplicate_parent (present plus slot4 exact duplicate). True generated parent is slot0 in present/parent_plus_impostor/duplicate_parent and absent in the other two. Duplicate identity cannot be inferred from the visible text, so duplicate panels must abstain. Public case/view IDs are hashes; source-origin metadata, key/group/mechanism labels and gold slots are separate from the scoring inputs. All cases remain; no feature-based selection.

## Frozen decoder and alignment readout

Decode a query token only by an admitted frozen mapping entry. Blocked or unadmitted forms receive null with explicit reason; no contextual alias, synonym, source-assisted fill or test-time update. Alignment permits a zero-cost diagonal only when a decoded nonnull source form equals the candidate's unblocked form. A query gap or candidate gap costs1. There are no mismatch diagonals. Compute a minimum global insertion/deletion cost; this equals `query_length + candidate_length - 2*matched_tokens`. Keep unknown/barrier tokens as penalized gaps rather than dropping them from sequence or denominator. Traceback tie priority is match, query gap, candidate gap. Save a deterministic representative path and the exact number of optimal operation paths; gap-order alternatives are not independent evidence or unique linguistic alignments.

Qualify only with at least24 known matched tokens and matched coverage >=4/5 of both full query and full candidate token counts (including barriers/unknowns). This fixed operating point permits the declared ordinary edit budget on seen vocabulary; it is not a natural-data-calibrated threshold. Rank all candidates by known match count, keep every top tie and nominate only a unique qualifying maximum. Otherwise abstain. Candidate slot labels/oracle metadata never enter scoring.

After the model freezes but before any pair alignment, decode all test queries and record counts/reasons. Potential availability is a public-input upper bound: for at least one candidate in the query's fixed panels, `min(known_query_tokens, unblocked_candidate_tokens)` could satisfy the same min24/4/5 qualification. This does not assert actual sequence compatibility. Retain every unavailable query and all panel variants. Report all-case and availability-conditional denominators separately.

Save per-pair trace indices linked to exact public token spans, known match count, minimum cost, optimal operation-path count and qualification. Assessment separately reports present-panel retrieval and exact positional-origin agreement among returned known-parent matches. Repeated symbol values can make origin positions ambiguous even when parent retrieval succeeds; no type equality is substituted for positional correctness. Unmapped query tokens must never appear as matched trace diagonals. Copied anchors receive no match credit.
