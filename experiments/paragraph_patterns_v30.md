## Structural score and decision

Enumerate every contiguous ten-token window wholly within each unit, including overlapping windows. Discard windows containing any blocked token. Canonicalize each remaining window by first-occurrence class IDs: `a b a c b` becomes `0 1 0 2 1`, regardless of word strings. An eligible fingerprint has at least four distinct types and at least two types occurring at least twice. All-unique strings and one repeated filler type are therefore ineligible.

The query/candidate score is the number of distinct eligible fingerprint types shared, with each type counted once even if it occurs many times. Preserve every query/source occurrence with exact relative raw spans and token indices. Qualification requires at least two distinct shared types. This is a fixed development threshold, not a calibrated probability. Rank every source candidate in the complete fixed panel by score, preserve every top tie, and nominate only a uniquely highest qualifying unit; otherwise abstain. Do not use nominated-page metadata, copied names, character lengths or source word meanings in scoring.

## Controls and search-wide conditional null

Create for each query an opaque consistent renaming of all token forms with the same token sequence and inherited barrier positions. It is a positive sensitivity control with no natural source status. Create an anchor-only frame at the same token count: copy blocked tokens in place and replace every unblocked token by a unique unrelated filler. Score each control alone; add the frame and opaque control separately to source-work-absent panels. Frame nominations must be zero. The opaque control deliberately shares repetition structure and can also fool localization; retain every collision/tie as an identifiability limit rather than claiming a source-specific discriminator. Reverse-query retrieval is descriptive, not an alternative success criterion.

For each draw 0–198 and every source candidate, sort the unblocked native token indices by the SHA-256 bytes of the UTF-8 string `v30|{draw}|{unit_id}|{index}` (index breaks hash ties). Assign forms in that order to the ascending unblocked positions; keep blocked positions fixed. Store all permutations before scoring, including identity draws if any. Use one common shuffled panel per draw for all three queries. Score every candidate; the null statistic is the maximum score across the entire searched panel. The observed statistic is likewise the full natural-panel maximum. Save all unit scores, ties and maxima for every draw. Report exact one-sided corrected tail `(1 + number(null_max >= observed_max))/200`, including ties. This conditions on these exposed units, segmentation, mask and token histograms; it is not a population significance test or proof of a linguistic relation.
