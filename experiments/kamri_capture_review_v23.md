# Experiment 23: bounded native/archival capture and independent-review preparation

Registered 2026-10-14 before raw acquisition. The whole FL posts for inventory entries 4 (Western esoterism) and 8 (Risk mathematics / war accountability) are fixed nominees: the first two additional experiment-21 PDF-backed groups ordered by original inventory entry. No name, word-count or matching-outcome selection. Denominator: two whole FL posts and two fixed publisher PDF windows. Both groups are already exposed; no untouched-group admission is possible from these nominees. Target 03:007 and candidate dictionaries are not used.

Publisher windows are fixed from the existing single-analyst QA receipt: Western PDF pages 90–94 and Risk PDF pages 1–3. Capture each entire publisher PDF, retain all FL post body prose if obtainable, and provide the fixed publisher window for review. Do not infer that this window covers the whole FL post. Source boundaries, language scope, correspondence and word meanings need independent review. Prior annotation English, lexicons, model outputs, name hypotheses and gap scores are excluded from the reviewer packet.

Run one native HTTPS request for each FL permalink, one for each registered publisher PDF, and one exact-URL Internet Archive CDX metadata query per FL post, regardless of native success. Primary request budget: six fixed requests plus at most one dated archive replay per post, total eight. CDX asks for the last matching HTTP-200 HTML capture not later than the registered cutoff, `limit=-1`, `matchType=exact`, JSON output and fixed fields. Admit only one valid data record, with matching original host/path (HTTP versus HTTPS explicitly treated as the same historical resource), fourteen-digit timestamp, HTTP 200 and HTML MIME type. Multiple/invalid records fail closed. If a valid record exists, make one `id_` raw replay request using its timestamp/original URL. If none exists, archive the unavailable/skipped route; no alternate timestamp, host, search, replacement or retry. Use the exact same finite procedure for both nominees.

Native capture and dated archival replay remain distinct. An archive retrieved today is not current-site evidence. Imported indexed excerpts and reading transcriptions never fill missing raw captures. Prefer an identity-confirmed native post for the reviewer packet; if unavailable, use an identity-confirmed nominated archival replay; retain all unsuccessful and successful routes separately. Post identity requires HTTP 200, curl success, exactly one `div.post-body`, a page title containing the frozen title, and a canonical/OG/final URL bound to the frozen native permalink. For archives also bind the CDX original URL and replay timestamp. Reject challenge/error pages and missing/multiple bodies. Body extraction removes only script/style/noscript, retains headings, superscripts, English prefaces and all other prose, and makes no automatic language or token-alignment labels.

Every request preserves command parameters, URL, HTTPS redirects, final URL, UTC start/end, HTTP status, curl return code, stderr, body and header hashes/sizes. Use fixed connect timeout 15 seconds, total timeout 30 seconds, at most three redirects, maximum body size 2 MB for FL/CDX and 12 MB for PDFs, no credentials, authentication/challenge bypass or disabled TLS verification. For an apparent sandbox/environment network failure only, allow at most one disclosed identical outside-sandbox diagnostic per requested route in a fresh directory, preserving the failed primary attempt. No diagnostic retry for TLS protocol errors, HTTP denials, content failure, timeout or unavailable archives. Diagnostic captures are distinct infrastructure receipts, not replacements for primary attempt outcomes; at most sixteen total requests including such necessary diagnostics.

Capture completeness means successful transport within bounds; HTML identity and extractable prose are separate gates. A publisher PDF must be HTTP 200, curl-successful, parse as a PDF, and contain the fixed page window. Bind its SHA-256 to the earlier publisher snapshot and QA selection before reusing the earlier normalized source text. If bytes differ, retain the new PDF for review but withhold current-bound normalized prose and require new extraction/edition review. Render all eight fixed publisher pages when PDFs parse, inspect images, and record same-analyst visual/extraction review separately from independent semantic review. No correspondence scoring or model executes.

Produce one review dossier per fixed nominee even if acquisition fails: native and archival route receipts, identity/extraction gates, current publisher PDF and fixed-page images if available, publisher window prose only when byte-bound, whole FL post text only from an identity-confirmed raw capture, and an empty review form. A complete paired review-material gate requires an identity-confirmed FL capture (native or explicitly archived), a valid publisher PDF/window, bound source prose and completed page-image QA. It does NOT accept semantic labels. When FL capture is missing, retain the source-only dossier and missing-material status rather than fabricating a paired review task.

Independent reviewer identity and independence declarations, source/language/boundary checks, span/word correspondences, counterexamples and uncertainty fields remain blank until another reviewer completes them. An automated verifier or this assistant's second pass does not count as independent semantic review. Independent semantic reviews completed, semantic training labels admitted, model evaluations and untouched-test admissions remain zero in this pilot. Raw-capture counts may increase without changing those gates. Record a prospective holdout plan: all existing inventory groups are exposed, reserve no fake fresh group, and require newly nominated unexposed connected works plus blinded review before future frozen predictions.

Freeze request plan, all captures, PDF diagnostics, image-QA receipt, dossiers, provenance decisions and holdout status before immutable execution. Independently verify URLs/budgets, metadata-derived replay selection, errors, hashes, transport/identity/archival distinctions, PDF/page/window binding, withheld reviewer answers, and preservation of experiments 1–22 and prior seals. Preparation guards outputs, requests refuse existing directories, and verification preserves its successful receipt. Failed capture or missing independent review is an availability outcome; accuracy/rejection metrics are unavailable, not zero. Changed routes, retry policy, source window, labels or acquisitions require a new registration.
