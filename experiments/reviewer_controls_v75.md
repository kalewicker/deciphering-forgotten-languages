# E75: terminal known-truth literal-clue control test

E74's five supplied observations were all genuine. Its complete, all-supported
return cannot show whether the reviewer would reject a false supplied claim.
Test that separate component question once, using controlled literal claims
whose truth can be computed without FL semantics or accepted source identities.
This is not another natural source review or an expansion of the stopped
alignment/pattern programme.

Use the unchanged Western E25 text exports and E26 span records. Fix five cases:
(a) W1's expression; (b) W2's three names in their recorded order; (c) W4's name;
(d) W3's FL span paired with W5's source span while claiming W3's full label;
(e) W2's unchanged spans with the three named anchors asserted in reverse order.
The first three claims are genuine, the last two deliberately false. Original
documents and historical annotations are not altered. W2's two cases share
identical material; the five cases are dependent controls in one exposed work.

Every claim uses the same precise rule: both supplied spans contain every listed
anchor in the listed order, nonoverlapping, after Unicode NFC/casefold and
whitespace collapse, with Unicode word boundaries. No punctuation/accent/spelling
repair or opaque-word interpretation. Preserve raw quote offsets separately from
normalized matching positions. Order case IDs by SHA-256 of
`v75-review-controls-fixed|TAG`, retaining all five, with no seed replacement.

Freeze the code, protocol, neutral prompt, case inventory, private oracle, original
text hashes and session configuration before a model call. Supply only the two
unchanged text exports, a material manifest, anonymous claims and blank return
template in a new isolated directory. Do not supply true/false labels, original
W identifiers, mutation tags, counts of positive/negative controls, prior reviews,
prior findings, experiment code or memory. The reviewer can know that claims
require checking, but is not told how many are false. No page images/PDF are
needed: this test concerns exact exported text, not visual fidelity or semantics.

Use the established fresh standalone Codex execution with memory use/generation,
user config, project instructions, hooks, plugins/apps, subagents, browser tools,
web search and tool networking disabled. Explicitly deny home, memory/session
directories and unrelated temporary paths. Probe the usual protected files plus
the private oracle; all must raise PermissionError. Verify supplied material is
readable and not writable before launch. Stop without launch on a failed probe.

One model attempt, five cases, 15-minute timeout, no feedback, repair, alternate
prompt/model, second batch or replacement control after outcomes. Retain the first
raw JSON return and trace, including invalid/incomplete/uncertain results. Before
assessment, record its SHA-256 and freeze that prediction receipt; then compare
with the oracle. Supported is correct for a genuine claim; rejected is correct
for a false one. Uncertain stays in the denominator and is not scored correct.
No confidence calibration, population false-positive estimate or causal E74/E75
comparison is warranted.

The registered component gate requires complete schema/ID/quote accounting,
all three genuine claims supported, both false claims rejected, zero false
supports and the verified isolation/attempt boundary. Any failed component stays
failed. A pass demonstrates only these five literal controls, not natural review
reliability, source specificity, opaque meanings or independent scientific review.
An independent verifier must reconstruct the anonymous cases, truth via all
ordered-occurrence combinations, predictions-before-assessment receipt, every
quote, gate, input hashes and session/probe/trace accounting.

Stop after this single component test, receipt and report, regardless of outcome.
Do not feed the answer key back to the reviewer. No new source acquisition,
natural target rescore, source/meaning admission or untouched unit is authorized.
E62/E70 remain closed, synthetic feature expansion stays stopped, and the
four-work independently reviewed natural benchmark requirement stays unchanged.
