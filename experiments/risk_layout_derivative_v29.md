# Step 29: Risk character-layout derivative

Register this engineering repair before extracting its primitives, constructing lines, or measuring concordance. The three Risk pages are already exposed development fixtures. This is not a blinded or independent linguistic experiment. Preserve v27/v28, all original packets/offsets, and every prior failed gate. No FL-to-source alignment, model, translation, source acceptance, network, new page, spelling/citation/hyphen repair or target rescore occurs.

## Fixed inputs and representations

Use only Risk publisher PDF pages 1–3 and the three unchanged v27 RGB page images, raw page texts and v25 legacy source window. Hash-bind v28 maps, visual receipt, registration and all 28 previous run manifests/seals. Pin pdfplumber 0.11.9 and the installed Pillow version in the machine plan. Primitive extraction saves every PDF character, including whitespace/empty glyph text, in native content order with an index, exact text, cumulative native-string Unicode offsets, matrix, font, orientation and bounding box rounded to six decimals. The native glyph string is a new derivative coordinate system, not a claim of PDF byte offsets or equality to pypdf offsets. Preserve all original coordinate systems separately.

Use every original raster pixel through a deterministic separator scan: RGB converted to Pillow L; dark means <=128. On rows at or below 55% of image height, retain every contiguous dark run at least 20% of image width and starting at or before 35%. Merge consecutive candidate rows when their row gap is <=2 pixels and both horizontal endpoints differ by <=2 pixels, comparing with the group's first run. Retain all run members and their pixel bounds, and map bounds linearly into PDF page coordinates. Select the uppermost candidate; retain all alternatives. These are raster hints, not semantic ground truth. No OCR, manual separator coordinate or selected crop is introduced.

## Character grouping and exact accounting

Accept rounded matrix orientations (1,0,0,1) as upright and (0,1,-1,0) as quarter-turn. Other orientations remain singleton unresolved lines. Upright baseline is page height minus matrix translation y; quarter-turn baseline is matrix translation x. Font em is the saved PDF size for upright characters and bounding-box width for quarter-turn characters. Group separately by orientation, sorting baseline then native index. A group includes characters within two points of its first anchored baseline, without anchor drift.

For upright groups only, attach a smaller group to an original larger group when its median em is <=80% of the target median and the target baseline is between zero and six points below it. Select least baseline distance, then first target native index. All targets and candidates are the original groups; compute assignments simultaneously and retain their provenance. This recovers superscript positions without deleting their digits. A group that can attach to a still larger group is not an eligible target, preventing attachment chains. No vocabulary or reported evidence span is consulted.

Within an upright line order by x0 then native index; within a quarter-turn lane order by negative bottom then native index (bottom-to-top reading). Other orientations retain native index. Insert exactly one ASCII space only when the geometric gap exceeds 15% of the smaller neighboring em and neither neighboring text already supplies whitespace. Preserve every character string exactly, including ligatures, punctuation, citation digits, misspellings and existing spaces. Store each original character piece with native index/offsets; every inferred space and line-ending newline is a separate synthetic piece with a reason and neighbors. Assemble upright lines by baseline and then rotated/unresolved lanes. No joining of page-edge or line-edge hyphenation occurs.

Each output page has the native glyph string, full derivative string, glyph/space/newline pieces and exact derivative offsets, line membership, attachment records, bounding boxes and role hints. Every native character belongs to exactly one line and glyph piece; every output code point belongs to exactly one piece. Native-index ordering reconstructs the entire native glyph string exactly. Empty-text glyphs keep zero-length pieces and membership. The derivative's source links are to exact PDF glyph text, native-string offsets and geometry; pypdf/legacy offsets are supplied only by all-occurrence concordance.

## Roles, concordance and continuity

Role priority: quarter-turn => rotated_margin_candidate; other unknown orientation => orientation_unresolved; a 1–4-digit line at top >=85% page height => page_number_candidate; below selected raster rule with median em <=95% of modal non-whitespace upright em => footnote_candidate; other below-rule lines => below_rule_unresolved; bottom <=15% page height => upper_band_candidate; otherwise body_or_unresolved. Modal em uses three-decimal values, highest em breaking frequency ties. Roles are layout hints, not article/footnote semantic labels.

For every full line independently enumerate all consecutive NFC/casefolded alphanumeric/mark-token matches in its own saved v27 raw page text and the unchanged legacy window, preserving raw target spans and unique/ambiguous/unmapped statuses. No first-match choice or deletion of short matches. Report revised denominators alongside the old v28 counts, without treating their difference as calibrated recall. Inventory the same bracketed comma-separated numeric citation pattern in raw page and derivative text; retain occurrences and key-count differences, without using it to tune the derivative.

For each adjacent page pair, inspect only the last/first body_or_unresolved lines (exclude every other hint). Record exact lines and offsets. Flag a continuation candidate when the left ends in an alphabetic word plus ASCII hyphen and the right starts with a lowercase alphabetic word. Retain the two pieces separately, without spelling repair. The known fixture expectation is page 2's `as-` followed by page 3's `tronomy`; it tests layout continuity around the footnote interruption, not the source hypothesis. Footnotes remain their own lines and are not linked across pages automatically.
