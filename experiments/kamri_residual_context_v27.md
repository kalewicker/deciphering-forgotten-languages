# Experiment 27: residual literal-token context with page-level alternatives

Register before extracting the new page views, generating queries or scoring. This is a new diagnostic after v26's preserved failed gate. It tests literal shared text outside the reported anchors, not unknown-language translation, independent review, direct-source identity or borrowing direction. No network, new document retrieval, OCR, spelling repair, anchor weighting, training or target-gap rescoring. Both positive works and all three exposed clusters remain in order.

Queries: W_names (appendix W2, expected publisher PDF page 91); W_saturn (W3/W4/W5, expected PDF page 94); R_spellings (R3/R4, expected PDF page 3). For each query take the smallest raw FL span covering its registered appendix observations, then extend by 40 lexical tokens on each side, clipped at the complete FL export's boundaries. Include all tokens intersecting the original span. Freeze exact raw offsets/text; no subsequent context-size selection. Tokenization is byte-for-byte the unchanged v26 Unicode alphanumeric/mark-run NFC/casefold rule, preserving original code-point spans and accents.

Block vocabulary is the union of normalized tokens in every v26 query anchor, including all three primary clusters and all three descriptive queries. Block these component tokens globally in both FL and publisher text. Blocked tokens are hard barriers; never delete them and join their neighbors. This excludes reported names, Saturn/Latin labels, the two spellings, the technical phrase and coevolving, including their components in other occurrences. No added stopword, name or vocabulary list is selected after scoring.

Candidate documents are the eight individual pages in the existing publisher windows: Western PDF pages 90–94 and Risk pages 1–3, re-extracted with the same pinned pypdf runtime. These provide four same-work alternative pages for each Western query and two for Risk. Include all nine non-nominated historical exports from v26 as a disclosed topical convenience panel. Seventeen page/export views total. Do not expand to unreviewed PDF pages or label these alternatives independent true negatives. Same-work alternatives are confined to the already selected windows. The full books and a representative matched-topic corpus are not tested.

Parse only those eight pages and preserve raw pypdf text, page numbers and source hashes as a versioned derivative. No line/footnote/citation repair. Newline/punctuation gaps are retained in raw spans but ignored by lexical-token matching; page boundaries are always hard document boundaries. Render all eight pages at PDFium scale 1.5 and inspect complete images. Record visual/extraction QA separately from semantic acceptance. Risk's old normalized text has different extraction choices; preserve each query's old nominated publisher-window view as a descriptive representation control, never as a successful replacement for raw-page results.

Every candidate page/export is split into 160 lexical-token windows, stride 80, all full starts plus the final full-length start if absent. Short texts contribute one unpadded whole-token span. Freeze every window before scoring; preserve overlaps and differing document lengths. Ranking takes the maximum window score for each document, retaining every tied best window. Do not count overlapping windows as independent samples.

Residual match rule: find exact normalized four-token seeds in both query and candidate with no blocked token, at least three distinct token forms and at least two tokens containing four or more alphabetic characters. Extend each seed maximally left and right while tokens agree and neither side is blocked or outside the saved query/window. De-duplicate identical maximal aligned runs; retain every run, both exact raw quotes/offsets, and all ties. Score lexicographically (longest eligible extended run length, number of distinct eligible shared four-token seed types). Qualification requires an extended run of at least eight tokens. Eight is a fixed diagnostic threshold, not a calibrated likelihood, semantic criterion or inferred author boundary. Shorter shared runs remain visible. A nomination requires a unique qualifying top document.

Per query freeze four controls: (1) exact FL query-context copy, as a positive implementation/sensitivity check; (2) v26-style ordered anchor-only frame, filled to 160 whitespace tokens with xqframe, using only that query's primary anchors; (3) the normalized lexical tokens of the FL context in reverse order, as an order diagnostic; (4) the unchanged legacy publisher-window export, as an extraction-sensitivity diagnostic. Twelve control views total. The positive context copy deliberately reuses FL text and is never counted as a natural source or source-identity evidence. Synthetic copies cannot establish direct attribution.

Two natural decisions per query: all seventeen views, then removal of every page from the nominated source work. Retain all rankings/scores in both. Primary gate requires all three unique nominations to equal the expected pages, zero qualifying source-absent nominations, zero anchor-frame qualifications, and all three exact-context positive controls to qualify. Reverse/legacy outcomes and all partial matches are descriptive; do not use them to rescue a failed primary result. Report implementation sensitivity separately from natural evidence. If the positive control fails, mark that query's sensitivity failure without replacing it. No adaptive lower n-gram length, shorter threshold, alternate context, source expansion or second extraction method after results.

An absent eight-token match means this literal-token procedure found no qualifying residual run in the tested contexts; it does not disprove translated/paraphrased reuse. A match could be quotation, a shared ancestor, a common phrase, copied context or extraction/boundary artifact. It does not establish a unique immediate source or meanings for surrounding unknown text.
