# Experiment 57: every shared-numeral occurrence and its original context

Audit the six shared numeric key types in the E56 reference/target inventories,
without rescoring or choosing a source-target alignment. All material is exposed
development data. Some contexts have appeared in older outputs and preparation;
this is not blind labeling or independent review. Freeze this protocol, config,
code/tests, E56/E52/E46 ledgers, original archival/native bytes and all 56 prior
manifests/seals before new selection/context annotations.

Derive shared keys from the exact numeric intersection of the two saved E56
inventories, in reference first-occurrence order. Retain EVERY admitted occurrence
on both sides, including repeated keys, original mixed-anchor indices and units.
The expected retained counts are derived from the frozen inventories, not an
assumed one-to-one list. No best LCS path or preferred occurrence pair is chosen.

Supplement this core with an exhaustive scan of the COMPLETE original exported
target text and parsed reference body using the unchanged numeric candidate regex
[0-9]+(?:[.,][0-9]+)*. Include every full candidate whose exact literal key is in
the shared set, including masked, boundary-rejected and outside-scope candidates.
Do not find a key as a substring of a larger numeric candidate or normalize its
punctuation. Preserve containing-unit IDs, every overlapping original mask reason,
and original Unicode alphanumeric/underscore/leading-decimal boundary tests.
Disjoint status precedence is retained, boundary_rejected, masked, outside_selected_scope;
all underlying flags remain visible. Membership must exactly reproduce the frozen
core inventory, or stop with an engineering discrepancy. Supplementary occurrences
never enter a new score. Preserve every occurrence even if context is unclear.

For every selected candidate save its exact original +/-120 Unicode-character
window, clipped only at document edges, plus a separate unit-clipped window when
one original scope unit contains it. These are original text coordinates, not
raw-byte or rendered-pixel coordinates. Stable IDs use side and text-order ordinal.

Record narrowly defined literal cues within 64 characters after the candidate,
clipped to its original unit when available: direct unit markers from the exact
case-sensitive set km, km³, km3, km^3, m, MHz, GHz, Hz, GeV, PeV, EeV, °, %,
or a numeric range following -, en dash or minus with an optional such marker.
Whitespace is permitted; word adjacency prevents partial unit-token matches.
Retain exact marker/range/endpoint strings and spans, without normalizing values,
expanding years, inferring omitted units or treating this limited list as exhaustive.
Ranges and marker strings are observations, not measured quantity equivalence.

Use original v38 archival replay bytes to reproduce exactly the saved target
post-body export (one div.post-body; remove script/style/noscript; join prose with
spaces). Retain its January 10, 2026 capture provenance and original digest. Use
the original v42 native HTML/receipt and E52 body/scope to reproduce reference
spans. Neither raw capture verifies 2018 wording/routing or current post identity.
No new rendering, screenshots, OCR, downloads or requests. All glyph statuses
remain not_visually_checked; a correct parsed-text slice is not a visual check.

After freezing the selection, annotate one review row per occurrence, with exact
evidence slices from its fixed window and a nonempty note. Source-side classes:
discrete_count, distance_or_length, volume, angle_or_phase,
calendar_or_campaign_date, other_or_unresolved. Classes refer to explicit English
context, not the truth of the publisher's scientific claims. Source evidence
must support the stated role, with ambiguity retained in other_or_unresolved.
No category may be projected into the opaque target. Every retained target row
has class opaque_context_unresolved; supplementary target rows use
declared_excluded_context. Target notes may identify exact symbols/range strings
but cannot assign opaque word meanings. Quantity correspondence stays unresolved,
opaque_meaning_admitted false and glyph_status not_visually_checked on every row.

Summarize side/status/source-class counts and per-key occurrence-ID inventories
and distinct literal marker sets. Multiple target occurrences/marker contexts
under one key must remain separate; no chosen pair or semantic agreement gate.
Engineering completion requires exhaustive coverage, exact slices and valid
side-specific review fields; visual and quantity-correspondence gates remain null.
No new scaffold/lexical/semantic scores, accepted source identities, independent
reviews or untouched units. Preserve E56's scores and all earlier failures.

Before selection, test repeats in all status classes, full-number/decimal
boundaries, exact direct/range cues and unit clipping, stale/missing core rows,
complete review evidence, forbidden semantic/glyph promotion and one key with
multiple marker contexts. Separately reconstruct every selection/cue/context
from original bytes and old ledgers, check review coverage/evidence arithmetic
and every previous manifest/seal. Shared parsing and same-agent review are limits:
verification can validate traceability, not independently ratify context judgments.
Stop after this audit. Public protocol/code/tests/reports only; raw text, context
packet, annotations and evidence stay on the local-only branch under PUBLICATION.md.
