# E73: retrospective coverage audit of the first automated return

Audit only the unchanged E72 Risk return against the earlier E26 evidence
appendix and exact E25 packet. This is a retrospective documentation audit on
exposed material, not a prospective review trial, semantic recall test, new
source search or second reviewer. Register the complete ledger and code before
computing its coverage counts. Prior reading already suggested omitted spelling
clues; there is no claim of outcome blindness.

Keep every Risk pair R1–R4 and every unmatched English block R5–R8 in the
denominator. Validate every old/new quoted span against the same exact UTF-8
texts and all declared hashes. Never normalize text for offsets. The earlier
records are selected, source-disclosed observations, not semantic ground truth
or an exhaustive source inventory. R2's two phrases differ and must stay unequal.

For each old pair, record all new-return FL/source span records that fully
enclose its original interval. Count a jointly documented pair only if one new
evidence or counterexample record encloses both old intervals on their proper
sides. Keep evidence and counterexample witnesses distinct. An FL interval in
a language observation plus a source interval in an unrelated counterexample
does not make a paired correspondence. Containment is documentation overlap,
not evidence acceptance; unknown/uncertain relationships remain unknown.

For each old unmatched block, record all returned FL spans that enclose it.
This measures exact-span documentation only. Absence from cited spans does not
mean the reviewer did not read it or discuss its topic in notes. Also search
all string values in the return for the two frozen unusual spellings from R3
and R4, using NFC/casefolded whole-word equality; retain counts and locations.
No alternative spelling, fuzzy matching or shorter token is tried after seeing
counts. Do not treat the two spellings as two independent source works.

Record each new evidence pair's two-sided interval overlaps with the four old
pairs, without rejecting a distinct new proposal for being different. A new
localized structural proposal can remain a useful uncertain lead; it is not
automatically corroboration, a new connected work or a validated meaning.

Preserve E26's failed copied-anchor gate and E27/E30's failed context/pattern
criteria. No natural rescore, repaired extraction, new page, new packet, external
model call or reviewer feedback is authorized. Stop after one coverage ledger,
an independently reconstructed accounting check and a concise decision report.
If coverage is incomplete, report that limitation; do not rerun E72 to obtain a
more complete answer or manufacture an admission. E62/E70 remain closed,
synthetic feature expansion remains stopped, and the four-work independent
benchmark requirement remains unchanged.
