# Experiment 64: offline archive identity and purpose-limited metadata admission

## Scope, exposure and preserved outcome

Use only the sealed E63 CDX record, replay bytes, receipts and headers for post01.
Zero research requests. E62's ANITA comparator route stays closed. E63's combined
post-admission gate remains **false**, its exports unavailable and source stage
skipped. Do not modify or reinterpret those original output files as passing.

This policy is explicitly developed **after observing E63's missing canonical/
og metadata**. Before registration, inspection also found one post-title link
and one timestamp bookmark, each with the exact original m=0 URL. These are new
observed identity channels, not independent sources or a blind policy test.
Freeze that disclosed evidence, the proposed use/criteria, code and adversarial
fixtures before executing this new adjudication. It is an exposed development
policy decision, not confirmatory validation of E63 or general layout robustness.

The useful bounded outcome combines the identity decision, a traceable body
view if justified, and an inventory of explicit citation URLs. No source is
selected or fetched; no numeric, lexical, alignment or semantic model runs.

## Fixed evidence requirements and allowed purpose

Reproduce the original index selection from saved bytes: exact original string,
query included, single CDX record and frozen cutoff, status200/HTML and valid
digest. Require both original receipts/artifact hashes/byte counts and complete
HTTP200 transport. Metadata requested/final URLs must equal the registered CDX
URL; replay requested/final URLs must equal the selected replay. Preserve the
original SHA1/Memento/title/body/challenge checks from the frozen E63 code, and
independently verify them. Archive metadata is provider-reported; digest/time
agreement is not an external signature or historical-publication authentication.

Add positive page bindings: exactly one post-title heading with the full known
E37 title; exactly one HTML title equal to Forgotten Languages Full followed by
that known title; exactly one `.post-title a[href]` with that title and exact
original URL; exactly one `a[rel~=bookmark][href]` with the same exact original URL.
Only casefold/whitespace normalization of title text is allowed. Link URLs match
literally, including m=0; no stripped query, alias, port, credentials or fragment
variant can satisfy either permalink channel. Keep DOM tag indices/text/hrefs.

Canonical and og:url fields are inventoried separately as absent, consistent or
conflicting. Absence is allowed only when all the archive and affirmative
permalink/title checks pass. Any present canonical/og value outside the exact
original URL or that same URL with the registered terminal ?m=0 removed causes
rejection. Duplicates and missing required permalink/title channels fail their
cardinality checks. Never ignore a conflicting field to admit a page.

If all checks pass, the only admission is **offline citation-metadata inspection
of this archive-bound development view**. It does not authorize source requests,
semantic training, retrieval/scaffold scoring, source identity, 2013/current
wording authentication or untouched-test status. All these permissions remain
false independently of material admission. Same-page title/bookmark links do
not count as independent corroboration of one another or of the archive provider.

## Traceable derivative and complete metadata inventory

Only upon limited admission, derive text from exactly one div.post-body, removing
script/style/noscript descendants and using BeautifulSoup get_text with a space
separator and strip=True. Keep the original URL, capture timestamp, raw SHA-256,
text SHA-256, Unicode length, exact transformations and restricted-use label.
This export is a new E64 derivative; do not populate E63's failed export fields.
No word meaning or source-language boundary is assigned by this operation.

Inventory all href-bearing anchors and literal HTTP(S) URLs in non-anchor text
inside the unique body, in original descendant order; exclude script/style/
noscript channels. Preserve unsupported URLs and all duplicate occurrences.
For hrefs store the global raw-DOM tag index and decoded attribute value; for
literal text URLs store the original body text-node index and half-open Unicode
span inside that node. These locators are not raw-byte or exported-text spans.
Do not resolve relative links or follow base href, image, navigation or source URLs.

Use the unchanged E37 citation recognizer to label explicit scholarly metadata,
preceded by a strict HTTP(S), default-port, no-credentials/malformed-URL guard.
The recognizer may describe arXiv, DOI and allowed-host PDF links and derived
request URLs, but none is selected or requested. Preserve identity grouping
and duplicate occurrence indices, compare only with E63's frozen known-URL
registry and label missing identifiers merely unrecorded in that incomplete
inventory. No new connected work or immediate source relationship is inferred.
Rejected material gets null export and citation inventory, not a zero-citation
finding. No prose comparison or proposed translation is displayed or scored.

## Checks and stop

Fixtures cover absent versus conflicting metadata; exact, missing, duplicate or
wrong permalinks/titles; digest/Memento/URL failures; derivative transformations;
all href/literal URL locators and duplicates; unsafe URI retention; and rejection
without downstream export. A separate verifier replays the full archive chain,
new identity checks, body derivative, URL inventory and purpose boundaries without
production v64 adjudication/export/inventory functions. Shared HTML parsing and
sealed E37 metadata recognition are disclosed; no independent scientific review
is claimed. Check all 63 earlier runs/seals, local/public suites, then seal,
checkpoint and publish appropriate files. Stop after this offline decision and
inventory. Any later source acquisition needs its own fixed registration and
identity/edition/coverage requirements; E63's unused source budget is not reused.
