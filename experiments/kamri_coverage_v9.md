# Experiment 9 registration: order, coverage, and matched negatives

Registered 2026-10-01 before panel generation or model scoring. Constructed engineering identity truth only; no semantic validation or winner promotion.

## Fixed panels

Calibration seeds 9401–9432 and fresh seeds 9501–9532: 32 worlds in each disjoint panel. Reuse the v7 pristine six-statement construction, with paired anchor levels **normal / zero**, source extents **full / half**, and three separate candidate-pool families **rotation / renamed / content_order**. There are twelve conditions per world, 384 per panel. Conditions sharing a world are paired, not independent; query duplicates within a world are intentional. No seed replacement, culling, parameter search, or outcome-dependent retry. Seed 99001 is an implementation fixture only.

Normal anchors use unchanged eligible the/and forms. Zero anchors substitute two unseen FL forms for those same occurrences, leaving English text, lengths, repetition, and generated identities unchanged. Half source availability retains only its first three statements while the FL query retains all six. Reference edges/tokens include only available source occurrences; save unavailable query identities separately. This tests a true partial source, not deletion falsely labeled as a full reference. The three-linked-atom admission minimum stays fixed.

Each pool contains the true source and three negatives: (1) rotate all words in each available statement by 1, 2, or 3; (2) bijectively rename unknown content words with three disjoint vocabularies, preserving all function words, token positions, repetition patterns, lengths and punctuation; (3) rotate just the content-token subsequence by 1, 2, or 3 while keeping function words fixed. Renamed negatives deliberately test an observational blind spot. Content-order negatives retain content bags but differ in generated occurrence order; duplicate text anywhere in a pool must fail preparation without replacement. Randomize candidate position once per world and share it across twelve conditions.

Save generated text, candidate family labels, identities, character spans, available/unavailable query identities, substitution keys, normalized inputs and acquisition receipts before execution. Scorers receive none of the answer IDs, labels, references, keys, density or extent values. Twelve previously inspected real queries remain development/audit only; ten calibrate real thresholds, two extra Misinfons blocks do not. No fresh real work. Preserve the unavailable Altruist archive and historical denominator. Do not add old synthetic packets to calibration or call them fresh.

## Eight fixed variants

Cross original and full tolerant v7 backgrounds with order off/on and coverage off/on. Preserve base search, frozen predictions/eligibility, query-only aliases, token decoder, weights, floor, gaps and admission criteria. For selected blocks compute the inherited full token-DP objective D, upper bound Uc over covered query tokens, upper bound Ut over all query tokens, and uncovered count N. Bound contribution per predicted token is 2, per unknown 0.5. DP scores remain exact +2, known mismatch −2, unknown 0.5 minus normalized center displacement, gap −0.75.

For order on numerator starts at D; order off substitutes Uc, the covered-token ceiling. Coverage on adds −0.75N and divides by Ut. Coverage off adds no uncovered cost and divides by Uc. Clip quality to [0,1], with zero denominator giving zero. **Both factors off uses quality 1 unconditionally**, preserving base strength exactly including empty paths. Multiply base strength by quality before ranking. Save D, Uc, Ut, N, cost, denominator, raw and clipped qualities for all combinations.

Order on / coverage on exactly reproduces the v8 multiplier. Order only scores covered blocks, coverage only tests missing-query costs with perfect within-block agreement, neither is the base. Clipping and denominators permit interactions; do not claim an additive causal decomposition. Base paths and decoded links must be identical across factor levels within each background. No source prose outside selected blocks is charged. All-unknown equal-length matches can receive quality 1; semantic content discrimination is not built into this method.

Real thresholds use the ten real development queries by the same wrong-work maximum rule. Seal calibration scores and thresholds before fresh/audit execution. Admission additionally needs positive margin >1e-9 and at least three linked FL atoms. Keep all zero ties, refusals and failed retrievals. A high calibrated threshold may refuse every true case; this is an outcome, not grounds to change criteria.

## Decision limits

These 32 fresh worlds cover one engineered schema and chosen negative families; twelve paired conditions do not multiply independence. Renamed-content indistinguishability is a designed limitation, not natural-language semantic validation. Partial availability and zero anchors test robustness without inducing new words. Real material is all development and single-analyst structural reference. Zero errors under universal refusal would not establish useful discrimination. No model or meaning is promoted; further work must follow measured limits rather than tuning against this fresh panel.
