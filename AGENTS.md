- Continue research only through the next bounded, registered evidence-producing
  step. Preserve frozen inputs, prior failures, criteria and denominators.
- At the end of every work turn, commit and push appropriate project changes on
  public `main`. This is the user's standing instruction from 2026-10-18.
- Checkpoint generated research evidence on local-only
  `local-evidence-2026-10-18`; preserve its earlier commits. Never merge that
  branch into `main` or push it. Follow the publication boundary in PUBLICATION.md.
- Keep downloaded documents, acquisition responses, review packets, environments,
  credentials and multi-gigabyte generated outputs off public `main`.
- Run checks appropriate to the change. Verify a clean public worktree and matching
  local/remote `main` before reporting a successful push. Report any push failure.
- Do not edit sealed historical scripts, tests, registrations, runs or reports.
  Use new versioned files for experiments and corrections. Public docs can evolve.
- Structural correspondence and English quotation presence do not establish
  opaque FL meanings, source identity, independent review or untouched test units.
